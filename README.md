# Homemade Stereo Camera

## Overview 
The homemade stereo project is a project that uses a raspberry pi to create a home made stereo camera that can be used to create depth maps that can be used for robotics projects. The project will aim to use a simple list of components to make it as accessible as possible for people to create their own systems and will include some code to be able to get it to interface with some of their projects at home. This project will be a cheaper alternative to an intel realsense system for those who are using a single board computer with a slighty reduced performance for a much lower cost and a robust api.
